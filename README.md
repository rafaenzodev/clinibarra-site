# Clinibarra

Site institucional da Clinibarra, clínica odontológica em Barra, Bahia. Apresenta a clínica, os tratamentos sugeridos, horários e localização, com agendamento pelo WhatsApp.

## Arquivos

- index.html — estrutura da página, SEO local e dados estruturados.
- styles.css — identidade visual laranja e branca e layout responsivo.
- script.js — menu mobile, status de funcionamento e animações acessíveis.

## Publicação

O site é estático e pode ser publicado diretamente na Vercel ou no GitHub Pages. Não requer dependências nem processo de build.

Antes da publicação, confirme os tratamentos oferecidos e o marcador exato do mapa, e substitua as áreas marcadas com TODO por logo e fotos oficiais, se disponíveis.
